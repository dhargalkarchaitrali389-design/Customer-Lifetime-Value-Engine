# Customer Lifetime Value Engine

A data analytics project that analyzes customer purchasing behavior and estimates Customer Lifetime Value (CLV).

## 📌 Project Overview

The Customer Lifetime Value Engine helps analyze customer purchase patterns and estimate the potential value of customers to a business.

## 🛠️ Technologies Used

- Python
- Pandas
- Streamlit
- Data Analysis
- Data Visualization

## ✨ Features

- Customer purchase analysis
- Purchase frequency analysis
- Average order value analysis
- Customer Lifetime Value estimation
- Interactive Streamlit dashboard

## 🎯 Objective

To understand customer behavior and generate insights that can help businesses improve customer retention and decision-making.
